# SamTripodAi (v2.1)

An automated rule-based extraction tool designed to audit and evaluate compliance with the 27 TRIPOD+AI reporting guidelines in clinical prediction model literature.

## Overview
`SamTripodAi` is a Python-based utility developed to assist researchers, methodologists, and reviewers in systematically assessing adherence to the TRIPOD+AI checklist items across predictive model studies. Version 2.1 features streamlined rule definitions, enhanced modular architecture (`extractor.py`, `rules.py`, `models.py`), and refined extraction logic for rigorous methodological audits.
